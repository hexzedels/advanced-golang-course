# Поправки к лекции 3 (модель памяти и atomics)

В записи лекции ошибки поправлены плашками, у каждой есть код [L3-NN]. Здесь подробные
разборы для плашек со словами «Подробно в репозитории курса».

Как читать разбор: что было сказано, как правильно, механизм в коде (со ссылками), проверка
замером (числа с машиной, на которой они получены), что не проверено и как проверить самому.
Картинки лежат в `assets/`, команды запускаются из папки `demos` (для L3-07 еще из `l3-07-probe`, для L3-20 из `l3-20-probe`).

- [L3-07](L3-07.md). Что такое happens-before и за счет чего его дают каналы, мьютекс и WaitGroup. Там же случай 05 демо 4 (L3-08).
- [L3-20](L3-20.md). ABA: CAS в стеке сравнивает указатели, а не bool. Там же ABI (L3-13).
